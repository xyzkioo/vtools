# v0.5.5 Windows 安装包验收

Windows x64 安装包采用标准 CPython 3.12 venv、固定依赖、React + PySide6 Qt WebEngine，内置轻量工具运行库，不依赖目标机器的源码、Git、Node、Conda 或 Python。

## 安装行为

安装器只读取目标目录的 Windows 完整性标签，不调整标签或安全策略。低完整性目录在准备阶段拒绝，不能误报成功。

准备阶段解包同一份运行资源，使用所选目录的 user-data，实际加载 React 页面、本机 API 版本与 Qt WebChannel。通过后才复制程序、生成快捷方式和注册卸载信息。失败返回非零退出码，不留下已部署的程序或快捷方式；可用的诊断日志保留在目标 user-data 中。
