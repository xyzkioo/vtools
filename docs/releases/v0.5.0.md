# v0.5.0 构建说明（2026-11-05）

本版增加 NDJSON 下载配置，降低默认下载并发，支持保存自动重试和超时设置。

## 更新内容

- “格式转换 → NDJSON → YOLO”新增“下载配置”按钮，沿用工作台配置弹窗样式。
- 默认并发 4，自动重试开启，首次失败后重试 4 次（最多尝试 5 次），单次超时 120 秒。
- 可保存并发数、自动重试开关、失败后重试次数与超时，下次运行生效。
- 重试等待逐次增加；重跑复用已下载图片，失败保持非零退出状态。

## 外部 Ultralytics 依赖

下载任务仍使用所选外部 Python 与 Ultralytics Fork，安装包不内置 PyTorch 或 Fork。
本机实际 Fork 的 converter.py 已加入 download_workers/download_retries/download_timeout/retry_delay 参数与临时文件写入。
其他机器必须同步此修改；旧版 Fork 将明确提示更新，不会静默忽略配置。

随本地构建另附 `dist/ultralytics-ndjson-download-0.5.0.patch`（不在 deb 内部）。在匹配的 Fork 仓库先检查：

```bash
git apply --check /path/to/ultralytics-ndjson-download-0.5.0.patch
git apply /path/to/ultralytics-ndjson-download-0.5.0.patch
```

补丁基于本机 Fork，其他版本需先检查适用性并验证；无需改写已有数据集。

## 安装

安装前校验附件，安装后完全退出旧工作台并重新打开：

```bash
sha256sum -c vtools_0.5.0_amd64.deb.sha256
sudo apt install ./vtools_0.5.0_amd64.deb
```
