## 变更

- 移除「格式转换 → NDJSON → YOLO → 下载配置」面板，以及 `settings.json` 中对应的 `ndjson_download` 字段。
- 原因：`download_workers`/`download_retries`/`download_timeout` 只存在于打过补丁的 Ultralytics Fork。官方版 `convert_ndjson_to_yolo(ndjson_path, output_path=None)` 只有两个参数，面板上的并发、重试次数、超时无法生效，旧实现遇到官方版会直接报「请使用已更新的 ultralytics-cn Fork」而无法转换。
- 转换改为直接调用 Ultralytics 自带接口，下载策略沿用库内默认（高并发、单张失败重试 3 次、单张超时 30 秒）。官方版与 Fork 都能直接转换，不再要求特定 Fork。
- 图片下载失败时提示：重新启动本工具即可续传，已下载的图片自动跳过。同一份 NDJSON 和同一输出目录重跑不会重复下载。
- 工作台「准备就绪」卡片在该工具下多一行提醒：「支持续传：同一份 NDJSON 反复运行会跳过已下载的图片，只补齐缺失的那几张。」
- 命令行 `--workers`/`--retries`/`--timeout`/`--auto-retry` 仍可传入但不再生效，仅用于兼容旧命令，且不在 `--help` 中显示。

## 边界

- 下载并发、重试次数和单张超时不再可配置，固定为 Ultralytics 库内值；网络很慢时个别 4K 大图可能超过 30 秒而失败，重跑即可补齐。
- 运行 NDJSON 转换的外部 Python 环境需要能导入 Ultralytics 和 `aiohttp`（官方转换器用 `aiohttp` 下载图片）。
- 旧版 `settings.json` 中残留的 `ndjson_download` 字段会被忽略，不影响启动。
