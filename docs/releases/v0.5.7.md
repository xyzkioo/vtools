## 行为变化

- 默认读取所选 Python 环境已安装的包，报告实际版本；不固定 Ultralytics 8.4.128，不要求克隆 Fork。
- 源码目录、期望版本均为可选输入；显式指定源码时仍核对路径，`--strict` 仅对显式指定的期望版本收紧比较。
- 仅运行用户指定的模型 YAML 或权重，不自动附加 YOLO26 检查；没有模型输入时明确提示只完成基础环境检查。
- 核心依赖缺失、导入失败、指定模型运行失败仍返回失败；可选导出依赖沿用普通模式警告、严格模式失败的规则。
- 环境检查页面、模块文档与安装包同步，保留 0.5.6 的外部 Python 隔离及 Qt WebEngine 桌面方案。

## 验证边界

本版调整环境检查规则，不安装 PyTorch、torchvision 或 Ultralytics。模型环境仍需具备实际运行所需的依赖；没有真实模型推理或导出成功的结果时，不表示该路径已经通过验证。
