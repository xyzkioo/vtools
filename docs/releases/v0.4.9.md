# v0.4.9 发行说明（2026-11-03）

本版将 v0.4.8 的审查修复与后续诊断标签错误提示一并打包。YOLO 标签无法按 UTF-8 读取时，诊断现在会报告具体标签路径和重新导出建议，并保持失败状态。

## 更新内容

- 检测压缩使用独立输入副本，避免上游修复或缓存扫描写回原始数据；分类训练和验证类别映射不一致时明确失败。
- 停止任务时清理进程组，修复直接脚本导入、无输入 pipeline 空跑、checkpoint 失败结果丢失及严格停止策略。
- 统一模块选择，拒绝跨工具诊断模块，清理 TensorRT 无效分支和旧配置；修正零 TP 的 F1、COCO BOM、改名冲突及重复层清单输出。
- 标准数据集 YAML 与旧式 YOLO 标签目录共用标签读取逻辑，二进制标签的错误提示包含具体路径。

## 安装包

- 文件：`dist/vtools_0.4.9_amd64.deb`
- Debian 元数据：`Package: vtools`、`Version: 0.4.9`、`Architecture: amd64`
- 大小：252,338,232 字节
- SHA-256：`4820c85d7473ce9d58c0f0e8093d1d524024c9ff7fbabb3a1f47223c83646767`
- 校验文件：`vtools_0.4.9_amd64.deb.sha256`

下载 Release 附件后，在下载目录执行：

```bash
sha256sum -c vtools_0.4.9_amd64.deb.sha256
sudo apt install ./vtools_0.4.9_amd64.deb
```

安装后完全退出旧工作台并重新打开。PyTorch、Ultralytics Fork、TensorRT、权重、数据集和 GPU 驱动仍由外部环境提供。
