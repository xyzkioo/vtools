# 桌面工作台

[返回模块导航](../README.md)

用 React 与 pywebview 统一配置编辑、任务启动、日志、历史和结果预览，任务仍调用各模块原有后端。

## 入口

从仓库根目录执行，`python` 指向已准备好的目标环境；系统仅提供 `python3` 时可替换命令名。

```bash
python -m vtools_ui
# 使用本地浏览器预览
python -m vtools_ui --browser
```

## 输入与功能

模型工具使用 YAML 和本次 CLI 覆盖项；数据工具使用页面参数。路径输入相对项目根目录解析，YAML 内部路径由各工具解释。设置中可选择 Conda、uv 环境或手动指定 Python。

安装版的图片缩放、视频抽帧、文件名转换、数据集检查及普通本地 GT 的已有预测诊断使用内置运行时；模型推理、测速、压缩、NDJSON 和 K230 路径仍需要所选外部环境。

## 输出

可浏览运行目录、JSON/CSV/文本、图片和 HTML，并跳转到模型产物目录。安装版模型任务默认输出 `~/.vtools_ui/runs/`，转换工具仍按显式输出路径保存。

## 使用边界

一次只运行一个任务，关闭窗口会停止当前任务。桌面窗口与浏览器模式的原生文件选择能力不同；前端源 HTML 不能直接双击使用。模型环境依赖按实际输入路径决定。

详细说明：[原模块文档](../../vtools_ui/README.md)。
