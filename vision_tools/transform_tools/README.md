# 各种转化脚本

模型有时会有不兼容的情况，这里有一些用于转换的代码

## 文件说明

| 文件                | 用途                                                |
|---------------------|-----------------------------------------------------|
| `ndjson_to_yolo.py` | ndjson下到本地的方法                                |
| `py2kmodel.py`      | pytorch模型转换成kmodel的代码（会产生一个onnx文件） |
| `PY2KM_validate.py` | pytorch模型转换成kmodel的验证代码 （需要onnx文件）  |
